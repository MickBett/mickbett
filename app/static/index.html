Import a game

Option A — paste the game's FIBA LiveStats link

Easiest: paste the normal boxscore page URL you'd open in a browser (fibalivestats.dcd.shared.geniussports.com/u/<code>/<matchId>/…) or just the numeric match id — the app fetches the game's raw data itself, no saving files required.

Option B — drop a JSON file

If you already have the data.json file saved (or it's from somewhere other than FIBA LiveStats), drop it in directly. You can drop several at once.
